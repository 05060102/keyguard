> A completely **free** online platform that protects your programs and documents with key-based licensing. No code, no install, no cost.

**KeyGuard 是一个完全免费的在线软件加密与授权保护平台**——给 EXE / APK / PDF 加上一把"许可证锁"，客户不输入密钥，程序就打不开。

## ✨ Features / 功能特性

| | |
|---|---|
| 🛡️ **EXE / DLL / JAR / APK 保护壳** | C++ native shell wrapping + license key verification — the app only runs when the customer enters a valid key |

| 🗝️ **License key management** | Batch key generation, expiry dates, machine-code binding, instant revoke/disable anytime |
| 🔒 **Anti-crack hardening** | Anti-debug, anti-reverse-engineering, string encryption, memory obfuscation, forced HTTPS |
| 🌐 **100% online** | Works in the browser — no SDK integration, no coding, ~40 seconds to protect your first program |

## 🚀 Quick Start / 快速开始

1. Open **keyguard.fun** → register & log in (free)
2. Drag & drop your program or file into the console
3. Generate license keys (卡密) and distribute the protected version
4. Customer enters the key to use it; machine-code binding prevents key sharing

1. 打开 **keyguard.fun** 注册登录（完全免费）
2. 控制台拖拽上传你的程序或文件
3. 生成许可证密钥（卡密），分发受保护版本
4. 客户输入密钥即可使用；绑定机器码可防止一码多用

**全程无需写代码，40 秒左右完成保护。**
**No coding needed — protect your first software in about 40 seconds.**

## ⚙️ Tech Highlights / 技术要点

- AES-256-GCM encryption on disk, plaintext never lands on server / AES-256-GCM 加密落盘，明文不落地
- C++ native protection shell (no .NET managed code, cannot be decompiled directly) / C++ 原生保护壳，无法直接反编译
- Machine-code signature binding, prevents key propagation / 机器码签名绑定，杜绝密钥传播
- Online revocation & unlock logs / 支持在线吊销、记录解锁日志

## 📝 Notice / 说明

Any software protection cannot be 100% unbreakable. KeyGuard's goal is to **significantly raise the cost of cracking**, making most cracking attempts pointless.

任何软件保护都无法做到 100% 不可破解，KeyGuard 的作用是显著提高破解成本，让绝大多数破解尝试失去意义。
